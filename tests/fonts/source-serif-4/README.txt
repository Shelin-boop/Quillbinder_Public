Source Serif 4, variable font (upright and italic), used only by the tests of
version 0.40.1 (tests/v0401_tests.cpp); it is not part of the program or the AppImage.

Why this font: it keeps several designs (the optical sizes Caption, SmText, Subhead
and Display next to the default design) in one family, each with its own Regular,
Bold and Italic, in the same way as Windows 11's Sitka (which cannot be shipped here).
