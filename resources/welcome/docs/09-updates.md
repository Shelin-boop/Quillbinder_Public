{{APP}} is one program file. Updates and extensions come as small package files ending in *.qbpkg*.
- Install one with **File > Install Update or Add-on…**, or double-click the file. {{APP}} checks the package, shows what is new, and tests a program update once before it is used.
- **Help > Add-on Manager…** switches add-ons on and off, removes them, and goes back to an earlier program version with **Use This Version**.
- If an update does not start twice in a row, {{APP}} goes back to the version built into the program file by itself.
- Add-ons bring extra themes, project templates, compile formats, writing tools (Name Generator, Scratch Pad, Text Statistics), audio and video playback, and the import of web pages and old Word files.
