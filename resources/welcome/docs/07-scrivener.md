{{APP}} reads and writes Scrivener 3 projects, so you can move between the programs.
- **Import**: **File > Import > Scrivener Project…** makes a {{APP}} project from a Scrivener 3 or 2 project. The binder, texts, synopses, notes, labels, status, keywords, snapshots, comments, footnotes, research files, and collections come along. The Scrivener project is only read.
- **Work in Scrivener format**: open the *.scrivx* file inside a *.scriv* folder with **File > Open Project…** and choose **Work in Scrivener Format**. {{APP}} then saves into the *.scriv* itself, so you can go on in Scrivener later, for example on another computer. Close the project in one program before you open it in the other.
- **File > Project Format** switches a project between the two formats, or saves a copy in the other one.
- A {{APP}} project of its own keeps every document as a plain text file (Markdown, or RTF if you prefer), readable with any editor.
