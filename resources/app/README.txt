The program icon of Quillbinder, drawn for Quillbinder (quillbinder.svg).
quillbinder-256.png is the same picture as a 256 x 256 px PNG (made with rsvg-convert),
used as the icon of the AppImage file (packaging/linux/build-appimage.sh).
Both are under the Zero-Clause BSD license, like the rest of Quillbinder's own files (LICENSE).
quillbinder.ico is the same picture at 16 to 256 px for Windows (rsvg-convert, then Pillow), built into
quillbinder.exe through quillbinder.rc (W4b, 2026-11-12).
